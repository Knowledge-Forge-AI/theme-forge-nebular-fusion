# Changelog

## 0.8.0 — Unreleased candidate

- Add paired-v2 profile authoring with editable briefs, Solar Sail and Stellar
  Loom previews, candidate packet exchange and review, application drafts,
  and explicit save/reopen workflows.
- Add six application appearance families in light and dark, System/Light/Dark
  controls, independent light/dark family pairs, saved preferences, reset,
  and bundled fallback appearances.
- Target macOS 13.3 or later on Apple Silicon. Native qualification and
  availability are recorded separately for each release and distribution channel.

## 0.7.0

- Select Stellar Burst 0.7.0, Stellar Loom 0.5.0 and Solar Sail 0.3.0 as the component version targets.

## 0.3.0 — Unreleased candidate

- Provide Brand/System, Vector/Graphics and Starlight Theme work areas.
- Consume authenticated Burst 0.5.0 and Loom 0.2.0 package inputs.
- Reject local non-Scene JSON with a selected-file diagnostic before engine
  invocation; preserve the fixed 42-command authority.
- Declare a product-local locked Rust 1.98.0 development environment.
- Classify editable Theme v2 fields through the maintained gallery authority.

The developer app is not Developer ID signed or notarized. The Homebrew cask is
withheld. The Scene workbench produces SVG; no distributed PNG claim is made.
