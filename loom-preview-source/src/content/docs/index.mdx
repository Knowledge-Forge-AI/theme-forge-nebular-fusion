## Architectural Overview

Theme Forge Stellar Loom (**TFSL**) provides a deterministic compiler and CLI that transforms typed, versioned theme specifications into canonical CSS custom properties for [Astro Starlight](https://starlight.astro.build).

#### Structured Lists

Architectural principles (unordered list):
- **Strict Data Model**: Zero inline executable code or CSS escape hatches in specifications.
- **Reproducible Determinism**: Canonicalized key sorting ensuring byte-identical digests.
- **Starlight Purity**: Mapped directly to public `--sl-*` tokens without runtime side effects.

Compilation pipeline execution sequence (ordered list):
1. Schema validation against `tfsl.theme-v1` specifications.
2. Canonical key sorting and normalized input digest computation.
3. CSS emission for Starlight custom property bindings.
4. Deterministic theme descriptor creation with provenance tracking.

### Code Blocks

```typescript
// Deterministic theme compilation sample
import { compileTheme } from "@knowledge-forge-ai/theme-forge-stellar-loom";

export function buildTheme(spec: unknown) {
  const result = compileTheme(spec);
  console.log(`Compiled: ${result.specification.name} (SHA-256: ${result.outputDigest})`);
  return result.css;
}
```
