# macOS native escape seam

This is a documentation-only escape seam. TFSB47H adds no Swift package,
Xcode project, Objective-C, AppKit code, bridging header, FFI, or unsafe Rust.

A later separately reviewed phase may activate a narrow native adapter only
after measuring a concrete Tauri/Rust deficiency in accessibility,
security-scoped bookmarks, lifecycle, packaging, or another specific macOS
integration. macOS arm64 is the only Studio target qualified here. Windows is
a possible later desktop port; mobile is not on the current roadmap.
